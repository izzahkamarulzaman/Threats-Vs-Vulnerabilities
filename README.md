
## Lab 1: Threats vs Vulnerabilities

## 1. Introduction

In cybersecurity, threats and vulnerabilities are important concepts for identifying and understanding security risks. A threat is something that has the potential to cause harm, while a vulnerability is a weakness in a system that can be exploited by a threat.

## 2. Objectives

- Identify different types of cybersecurity threats and vulnerabilities.
- Understand the differences between threats and vulnerabilities.
- Identify examples of security weaknesses and potential attacks.
- Understand basic methods for preventing cybersecurity risks.

## 3. Threats

A threat is any person, event, or condition that has the potential to cause harm by exploiting a weakness in a system.

### Examples of Threats

- **Phishing:** Tricking users into revealing their login details.
- **DDoS Attack:** Flooding a website with traffic until it becomes unavailable.
- **Insider Threat:** An authorized person misusing their access to steal information.
- **Ransomware:** Malicious software that can encrypt files and demand payment.
- **Social Engineering:** Manipulating people into revealing sensitive information.

## 4. Vulnerabilities

A vulnerability is a weakness or flaw in a system that can be exploited by a threat to cause harm.

### Examples of Vulnerabilities

- **Outdated Software:** Software that no longer receives security updates.
- **Exposed API Keys:** Sensitive keys accidentally uploaded to a public repository.
- **Misconfigured Firewall:** Incorrect firewall settings that allow unwanted traffic.
- **Weak Password Policy:** Allowing users to create easily guessed passwords.
- **Poor Input Validation:** Failure to properly check user input, creating a risk of SQL injection.

The following table presents 10 scenarios and classifies each one as a threat or vulnerability.

| No. | Scenario | Category | Reason |
|---|---|---|---|
| 1 | An employee receives an email from "HR Department" asking them to verify their login details through a link. | Threat | Phishing attempts to trick users into revealing their credentials. |

| 8 | Cybercriminals send ransomware through email attachments to multiple employees. | Threat | Ransomware is a malicious attack that can encrypt files and demand payment. |
| 9 | A company's website does not validate user input in its contact form, creating a risk of SQL injection. | Vulnerability | A coding flaw may allow malicious SQL commands to be submitted. |

## 6. Prevention and Mitigation

The following practices can help reduce cybersecurity risks:

- Keep operating systems and software updated.
- Use strong passwords and multi-factor authentication.
- Configure firewalls properly.
- Avoid clicking suspicious links or email attachments.
- Never publish API keys, passwords, or other secrets in public repositories.
- Validate user input to reduce the risk of SQL injection.
- Perform regular vulnerability assessments and security checks.
- Educate users about phishing and social engineering.

## 7. Conclusion

Threats and vulnerabilities are related but different cybersecurity concepts. A threat has the potential to cause harm, while a vulnerability is a weakness that can be exploited. Identifying vulnerabilities and understanding threats helps organizations protect their systems, data, and users.
